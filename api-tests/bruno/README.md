Every registered `/api/v1` route has at least one request, including negative and authorization tests.

The route→file map lives in [`docs/waffrli/api-inventory.md`](../../docs/waffrli/api-inventory.md), generated by `php artisan waffrli:api-inventory`.
`tests/Feature/ApiInventoryTest` fails the build when a route has no Bruno request, or when a request calls a route that does not exist.

Two kinds of routes are never required:

- the development-only `GET /api/v1/dev/otp`;
- the legacy starter email/password routes, which ship disabled (`WAFFRLI_LEGACY_USER_AUTH=false`).

## Quick start (Docker)

1. Start the stack and seed demo data (`scripts/setup.ps1` or `scripts/setup.sh`).

2. Install the Bruno CLI (`npm i -g @usebruno/cli`) or use the Bruno desktop app.

3. In each collection folder, copy `.env.example` to `.env` (git-ignored) and fill it in:

   - **Customer**: `WAFFRLI_DEV_OTP_PEEK_TOKEN` must equal the server's value in the root `.env`. `setup` generates it.
   - **Driver**: choose a demo driver password with `docker compose exec app php artisan waffrli:demo-driver-password`.
   - **Admin**: a local Super Admin from `docker compose exec app php artisan waffrli:create-super-admin`.

4. Run each collection:

   ```bash
   cd api-tests/bruno/WAFFRLI-Customer
   bru run --env Local
   ```

`Local` points to `http://localhost:8080`, which is Nginx in `compose.yaml`.

Run the collections a minute apart: OTP cooldowns and auth throttles are real and return 429 on rapid re-runs.

PowerShell users: `bru run --env Local` works the same way.

## Generators

The `.bru` files are generated from `generators/{customer,driver,admin}.py` (Python 3, standard library only):

```bash
python3 api-tests/bruno/generators/customer.py
```

A generator rewrites its collection but keeps `.env`, `fixtures/` and `README.md`. Edit the generator and re-run it; do not edit the generated files by hand.

## Secrets

Nothing secret is committed. Passwords, OTP peek tokens and phone numbers come from each collection's git-ignored `.env`.
Tokens are runtime variables only.
